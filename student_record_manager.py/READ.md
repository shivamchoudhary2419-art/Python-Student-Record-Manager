# Day 2 - Student Record Manager V2

## Overview

This project is a menu-driven Student Record Management System developed in Python.

## Concepts Practiced

* Functions
* Function Arguments
* Lists
* Dictionaries
* File Handling
* Loops
* Conditional Statements

## Features

1. Add Student
2. View Students
3. Search Student
4. Delete Student
5. Save Students to File
6. Load Students from File
7. Exit Program

## Data Structure Used

```python
students = [
    {
        "name": "Alice",
        "age": 20,
        "grade": "A"
    }
]
```

## File Handling

Student records are stored in a text file named `students.txt`.

## Learning Outcome

This project helped me understand:

* How to organize code using functions
* How to store records using dictionaries and lists
* How to save and load data from files
* How to build a menu-driven Python application
